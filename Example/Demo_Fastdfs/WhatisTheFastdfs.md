# 分布式文件系统与 FastDFS 简介

## 一、什么是分布式文件系统

随着互联网应用的快速发展，海量数据的存储与访问成为许多系统必须面对的核心问题。传统的单机文件系统在存储容量、读写性能以及可靠性方面都存在明显的瓶颈，难以满足大规模应用的需求。分布式文件系统（Distributed File System，简称 DFS）应运而生，它通过将数据分散存储在多个物理节点上，对外提供统一的文件访问接口，从而实现了存储容量与性能的水平扩展。

## 二、FastDFS 的架构设计

FastDFS 是一款开源的轻量级分布式文件系统，由国内开发者余庆设计实现，主要面向中小型互联网应用的文件存储场景。它以 C 语言编写，具有高性能、低资源占用的特点，特别适合存储图片、视频、文档等中小型文件。

FastDFS 的架构主要由三个角色组成：

- 客户端（Client）
- 跟踪服务器（Tracker Server）
- 存储服务器（Storage Server）

## 三、文件的上传与下载流程

在文件上传过程中，客户端首先向跟踪服务器发起请求，获取可用的存储服务器地址。跟踪服务器根据当前各组的负载情况返回一个存储节点，客户端随后直接与该存储服务器建立连接，将文件内容上传。存储服务器在接收文件后，会生成一个全局唯一的文件标识（File ID），该标识由组名、虚拟磁盘路径、两级目录以及文件名等部分组成，客户端凭此标识即可在后续访问中定位到该文件。
